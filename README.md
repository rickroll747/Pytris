# How To Install And Play
# Windows
## 1.0
1. Download The Zip File From The Releases And Extract It.
2. Open The Folder Named 'Windows' And Then Open The Executable.
## 1.1
1. Download The Zip File From The Releases And Extract It.
2. Open The Folder Named 'Windows' And Then Open The Executable.
# Linux
## 1.0
1. Download The Zip File From The Releases And Extract It.
2. Open The Terminal From The Directory
3. python3 pytris.py
## 1.1
1. Download The Zip File From The Releases And Extract It.
2. Open The Terminal From The Directory
3. python3 pytris-1.1.py
## Controls: 
1. ← → To Move The Shapes
2. ↑ To Rotate The Shapes
3. ↵ To Drop The Shapes
