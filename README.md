# How To Install And Play
# Windows
1. Download The Zip File And Extract It.
2. Open The Folder Named 'Pytris' And Another One Inside It Named 'Windows (Compiled To EXE)'
3. Open The Executable.
# Linux
1. Open terminal
2. git clone https://github.com/rickroll747/Pytris/
3. cd Pytris
4. python3 pytris.py
## Controls: 
1. ← → To Move The Shapes
2. ↑ To Rotate The Shapes
3. ↵ To Drop The Shapes
